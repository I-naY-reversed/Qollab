# Repeater Run art assets

Decorative art generated with Google Gemini on Oct 11, 2026 from text prompts written by the team, then resized and converted to WebP. The README discloses it. The background is the page colour #16222b (no transparency).

| File | Content | Layout |
|---|---|---|
| banner.webp | Toronto to Montreal night map, fibre line with repeater nodes; left third kept dark for the title | 1600 x 397, single image |
| station.webp | Repeater station: idle, photon arriving, storing (blue core), joining (plum flash) | 4 equal square frames in one row |
| photon.webp | Single photon, glow pulsing for a loop | 6 equal square frames in one row |
| purify.webp | Two noisy pairs, compared (gold link), lower pair dissolves, one cleaner pair remains | 4 equal square frames in one row |
| emblem.webp | Padlock with an entangled pair inside a gold ring (key success) | 512 x 512, single image |

Unused alternative takes and the earlier versions are kept outside the repo in `IonQ Hackathon/gemini-v2/` and `gemini-raw/`.
